A simple and responsive **Currency Converter Web App** built using **HTML, CSS, and JavaScript**.
It fetches real-time exchange rates using the **Currency API** and dynamically updates country flags based on selected currencies. 

---

## ✨ Features

* 🌍 Convert currencies in real time
* 🚩 Dynamic country flags
* 🔄 Live exchange rate updates
* 📱 Responsive UI design
* ⚡ Fast and lightweight
* 🛡️ Input validation for invalid amounts

---

## 🛠️ Technologies Used

* HTML5

* JavaScript (ES6)

## 🚀 How It Works

1. User enters an amount
2. Selects source currency
3. Selects target currency
4. App fetches live exchange rates
5. Converted amount is displayed instantly
